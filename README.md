# E-Cell Website

Official website for the Entrepreneurship Cell (E-Cell) at your institution.

## Live Demo
[View Live Site](https://ecell-website-gilt.vercel.app)

## Features
- Modern, responsive design
- Event listings and registration
- Team showcase
- Startup resources
- Interactive elements

## Tech Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- shadcn/ui
- Vercel Deployment

## Setup

```bash
# Clone the repo
git clone https://github.com/BalaKrishnan1708/ecell-website.git
cd ecell-website

# Install dependencies
npm install

# Run development server
npm run dev
```
